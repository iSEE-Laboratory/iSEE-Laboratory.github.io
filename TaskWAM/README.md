# TaskWAM

TaskWAM research project page, hosted in the shared iSEE-Laboratory projects website at [isee-laboratory.github.io/TaskWAM/](https://isee-laboratory.github.io/TaskWAM/).

This directory is a self-contained static website with no build step. All assets use relative paths. Preview `index.html` through a local web server.

The shared repository publishes its `main` branch from the repository root. Changes to this `TaskWAM/` directory are served under `/TaskWAM/`; keep the shared repository's publishing configuration unchanged.
